# AUTO COMPOSE

スタイルと長さを選んでボタンを押すだけで、オリジナル楽曲を全自動で作曲するブラウザ完結の作曲ツール。サーバーには何も送信されず、作曲・再生・書き出しのすべてが `Web Audio API` によりブラウザ内で処理されます。

## できること

1. 4つのスタイル（Lo-fi Chill / Epic Cinematic / Pop Upbeat / Ambient Piano）と長さ（30秒 / 1分 / 2分）、キー（指定 or ランダム）を選ぶだけで作曲を開始
2. コード進行・メロディ・ベースライン・ドラムパターンをスタイルごとの音楽理論ルール（ダイアトニックコード、コードトーンに寄せた旋律生成、イントロ/メイン/アウトロの展開）に沿って自動生成
3. すべての楽器（ピアノ/エレピ/パッド/ベース/プラック/ブラス/ドラム類）を既存の音源ファイルを使わず `Web Audio API` のオシレーター・ノイズ・フィルターでその場で合成
4. 生成した楽曲をその場で再生（ピアノロール風の可視化つき）
5. **WAV**（`OfflineAudioContext` によるレンダリング）または **MIDI**（自前実装のSMFエンコーダ）としてダウンロード可能。MIDIはDAWに読み込んで編集できます
6. 「同じ設定でもう一度作曲する」で、スタイル/長さ/キーはそのままに新しいバリエーションを再生成

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
```

外部の音源・ライブラリへの依存はなく、`vite` と `typescript` のみで完結します。
